# Debugowanie

1. Logi: `~/Library/Logs/ScreenForge/screenforge.log`
2. Włącz „Tryb developerski” w Ustawieniach → Zaawansowane (PerformanceMonitor).
3. Historia / obrazy: `~/Library/Application Support/ScreenForge/`
4. Recovery dokumentów: `~/Library/Application Support/ScreenForge/Recovery/`
5. Jeśli skróty nie działają — sprawdź konflikty w Ustawieniach → Skróty i zarejestruj ponownie (restart aplikacji).
6. Po zmianie uprawnień Screen Recording uruchom ponownie aplikację z `/Applications/ScreenForge.app`.
